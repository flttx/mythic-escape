# 01 · 克拉肯：深渊苏醒（Kraken / Abyss Awakens）

> 状态：完整关卡设计案 v0.5，**第一个 Vertical Slice**；当前尚无可玩地图。共享规则详见 `../ARCHITECTURE.md`。不以概念图代替 UE 实测画质。

## 核心体验
玩家坐在一艘真实可控的小型木船上，克拉肯从暴风海面和巨大漩涡中现身；玩家必须连续经历**逃离旋涡 → 躲避巨大触手 → 船被必然顶飞砸碎 → 游泳逃生**。克拉肯最后没入海中，海面恢复平静。重点不在“船追逐怪物”，而在巨兽缓慢运动引发的灾难改变玩家的位置、载具和逃生方式。

### 场景与路线
- **地点**：无人海域，远处可见灯塔/岛礁作为方向参照，暴风云层、风雨、山状巨兽背影形成分层尺度。
- **空间分区**：A 平静外海出生点 → B 漩涡外围环形水域 → C 触手走廊（非固定笔直通道）→ D 剧情托举/坠毁海域 → E 开放游泳危险带 → F 边缘安全水域。克拉肯世界锚点在漩涡核心，玩家距离是真实世界空间上的变化。
- **路线引导**：海浪方向、灯塔暖光、HUD 弱提示、海面危险阴影；尽量不放巨大浮空箭头。

## 阶段分镜与可玩规则（v0.5）
| 段落 | 玩家决策与独有体验 | 克拉肯持续存在的证据 | 通过、恢复与致命失败 |
|---|---|---|---|
| K0 寂静航行 | 熟悉船舵和观察，远处灯塔指示初始航向 | 海鸟飞散、沉闷的海底呼吸、黑水向中心缓慢汇聚 | 进入预兆区触发 K1；无倒计时，不安排无预警即死 |
| K1 巨兽现身 | 玩家仍可自由看向头部、触手与海面，尽量不强制锁镜 | 漩涡扩大、触手依次起身、山一样的外套膜现身 | 头部破海、主体尺度可辨且演出事件到位时 `RevealComplete` → 当前配置的唯一主计时开始（Prototype 240s；Full 720s） |
| K2 漩涡挣脱 | 观察水流和船首朝向，逆径向吸力选择较弱流带；方向键连续快速输入可作**可选增益**，稳定长按仍能通关 | 头部缓慢转动使漩涡/浪高改变，水花与船身实际受力一致 | 到达外环出口且摆脱径向回卷→K3；短暂偏航允许修正，持续进入不可恢复的核心坍陷区才吞没失败 |
| K3 触手围猎 | 读海面阴影、鼓包与触手蓄力，避开拍击/横扫/封路；玩家在出现危险时可控制船速与舵角 | 远处巨兽目光移动，巨型触手与主体锚点关联，触手留下真实浪涌 | 穿过可达的 C→D 安全航道并存活→K4；擦碰先失速/船体受损，直接致命砸击或撞毁才失败 |
| K4 剧情托举与碎船 | **已完成 K3 操作挑战的奖励式高潮**，触手从船底托起木船，玩家可回头俯瞰巨兽与岛状身躯 | 触手托举导致浪墙，坠落前能看到海域尺度，船砸海粉碎 | 这是剧情转折，不是随机攻击、不是死亡；计时暂停，坠入 E 的**风暴外围带**，自动安全切换到游泳，落水后有短接管保护 |
| K5 游泳求生 | 从风暴外围 E 游向有海流遮蔽的 F，冲刺/休息与短潜水规避横扫；体力耗尽仅减速，缺氧有清晰逐级警告 | 身后远景巨兽仍然运动，旁侧最后几条触手从水下通过，风暴边界可视 | 跟随外向缓流穿过 F 的逃生门，确认危险解除→K6；致命触手、持续窒息或超时失败，轻微浪涌可纠偏 |
| K6 劫后余生 | 倒计时停止，玩家能够自由回头 | 克拉肯缓慢沉没，最后一条触手入海，乌云与巨浪渐散 | 演出可跳过，结算不需要再游向“几公里外的绝对安全点” |

### 节奏与主倒计时（调参假设）
- **区分双档而非单一时限**：PrototypeSlice 从 K1 `RevealComplete` 起跑 240s，K2/K3/K5 正常目标 45/60/65s，共 170s、容错 70s；FullChapter 从同一揭示节点起跑 **720s**，三段正常目标 **160/200/180s = 540s**、容错 180s。均为可操作时间的设计假设，阶段没有独立硬截止，用真实首通与不同种子调优。
- K4 不可操作剧情暂停计时，跳过剧情也同样转入 K5；其它可驾驶/游泳期间不暂停。若需要剧情引导，HUD 只显示当前阶段目标，不再弹三段重复计时条。
- 大多数致命触手以可见海面变形 + 定向音频/字幕预警；实际预警长度依当前船速、舵响应和脱险距离测量，初始可按约 1–2 秒试验，**不是把 1 秒当保证公平的阈值**。随机触手不能同时封住所有路线、不能连续出生在船体碰撞框内，唯独 K4 的触手属于不可伤害的预定演出。
- K5 体力归零先影响速度，只有清晰氧气/致命危险造成死亡；玩家切换到游泳获得短暂无伤接管期，避免强制动画结束即遭攻击。
- K3 触手击中水面时，明确先动、后触水、再浪涌，视觉与物理打击不能错位。

### 安全区、失败与重试
- **F 区不是距离克拉肯几百米的随机圆圈**：K4 已将玩家与船抛向更远的漩涡外围。F 的外向海流/礁群形成局部遮蔽，触手有效攻击范围在此收束；HUD 显示的是“脱离危险海域进度”。
- 胜利契约：`K5 已穿越 E→F 的有效路线门 && 玩家位于 F 避险水域 && 当前有效触手/回卷力场不再覆盖玩家`。检查边界抖动时不因同帧计时归零错判；玩家达到条件才停止计时，随后开始沉海演出。
- 失败分层：K2 被彻底卷入核心、K3 船只受到致命砸击、K5 致命触手或氧气耗尽、主计时归零；船被 K4 托起摔碎**永不计失败**。普通刮碰导致减速/修正机会。
- K2/K3/K5 阶段练习检查点恢复船体或游泳状态、巨兽/浪流相位、剧情与适量预置剩余时间；完整版可在长段内设置稳定子节拍恢复锚点；练习成绩与短版成绩均不得冒充正式版无重试成绩。
- **可玩性验收**：预警后船与泳者仍有可达躲避路径；同一随机种子回放攻击一致；K4 前后镜头方位、操作状态和倒计时没有丢失；安全区不在巨浪/触手仍覆盖时提前判胜。

## v0.5 正式版时长扩展与阶段内节拍

**两套独立配置**：`PrototypeSlice` 保留 5–7 分钟完整玩法样本（主倒计时 240s，K2/K3/K5 正常目标 45/60/65s）；`FullChapter` 首次完整体验目标 **14–18 分钟**，正式主倒计时从 K1 结束起算 **720s**，K2/K3/K5 正常目标 **160/200/180s = 540s**，初始**容错 180s**。从一个档位切换到另一个档位须切换距离、节拍、事件与检查点配置，绝不将水流/触手动画简单播放 3 倍。

**原型版的开场也必须压缩**：K0 用约 30–60s 教会船只基础方向，K1 约 40–60s 显示最必要的克拉肯巨物登场，K4 与 K6 演出可短播放/跳过；用 K2/K3/K5 正常约 170s 的目标路径完成验证。P0/P1 不加载正式版 3 分钟探索和长距离路线，否则无法达到 5–7 分钟原型目标。

| 内容区域 | 正式版内部节拍（保留 K0–K6，不新增主逃生阶段） | 作用 |
|---|---|---|
| K0 探索（约 3 分，不计时） | 导航小船经过旧浮标、异常水色、漂浮船骸；可选靠近信号残骸或观测不自然涌流 | 玩家熟悉惯性与漂流方向，提前知道外环灯塔/礁群是逃离方位；可绕过观测点 |
| K1 巨兽揭示（约 1.5–2 分，不计时） | 海面异变逐级蔓延，触手/头部及远景体量相继揭示 | 玩家自由看巨兽，达到真正可辨的 `RevealComplete` 后才计时 |
| K2 漩涡（正常 160s） | **内环判断**：比较两股回旋水流；**中环换道**：在弱流带与较短湍流道之间择路；**外环突围**：根据真实浪流和船首朝向冲向有效外流通道 | 增加空间判断，不循环让玩家长按逆旋力；中途较稳水域可观察远方克拉肯并判断下一次流向 |
| K3 触手（正常 200s） | **首次触手学习**：读水面鼓包；**残骸密集区**：借破船和触手动作选择宽/窄航线；**尾段高潮**：两类明确先后出手的触手组合，留有一条可达航道 | 触手力度、主体眼神和船身浪涌具有事件因果；中途一次安全外流带让玩家喘息、回头看巨物 |
| K4 必经船毁（短不可控段暂停计时） | 已通过 K3 逃生挑战后，船被触手托举、玩家短暂俯瞰巨兽全貌，再跌入 E 外缘 | **不会被算作失败**，短暂无伤保护让玩家取得泳者控制权 |
| K5 游泳（正常 180s） | **辨认外向缓流**：选择水面加速或短潜避扫击；**危险暗影带**：利用漂浮残骸/浪涌预警进行路径判断；**最后外流门**：根据水流和礁群的安全边界进入 F | 保持弱势生存感，但氧气/体力可读且允许恢复；不要求游离岛屿级巨兽的几公里物理距离 |
| K6 结尾（约 1–1.5 分） | 安全后可以停下来回望巨兽缓慢沉入海底、风浪逐渐平静 | 有可跳过的释放段，计时已冻结 |

**扩展验收**：K2/K3/K5 各自不能超过一段连续 60s 毫无新判断的重复受力/攻击；危险之间的观察点依然消耗主计时但无无预警致命伤害。至少测试两条可行 K2 水流线、两种 K3 危险组合、K5 水面/潜水双策略。对话/地图探索不是强制收集任务。压缩原型继续使用旧版短预算验收，并在开发进入完整版前保存可回退基线。

## 巨兽实体、资产与动画
- 主体：章鱼/乌贼系克拉肯，巨大中央躯体、两侧眼部、吸盘、海洋附着物；**不变成克苏鲁人形头部**。远景时主体和云/浪协同说明规模。
- 触手：独立可绑定骨骼的近景攻击段（局部高细材质、有效碰撞）+ 低开销远景装饰段；每条遵循 Warning→Windup→Strike→Recover，位置随机但受公平约束。
- 船：木船未破坏体 / 分裂体 / 可漂浮残骸；设计相机与玩家的载具切换，不依赖全实时不稳定物理。
- 水：Water 起点、特殊漩涡流场、泡沫与体积雾；攻击溅水来自同一事件。海面可用近景可变形区 + 远景浪层混合。
- 声：超低频苏醒、触手跃出冲击、沉没声、落水后的隔水声场；预警有视觉替代。

## 操作与失败可理解性
- 第一人称鼠标自由看；船的前后动力/左右转舵在 UI 明确提示；从木船转游泳时不突然反转移动方向。
- 漩涡失败：即将卷入前有水流加重、倾斜与音效升级；被吞沉没短演出可跳过。
- 触手命中：受击位置、溅水/阴影与碰撞一致；禁止刚出现即造成伤害。
- 坠船剧情应通过明确阶段切换表达“故事推进”，不要求玩家提前猜测无法躲避攻击。

## 验收镜头与游戏测试
- A 木船镜头看巨兽头部现身与触手整体尺度；B 俯瞰漩涡深度及流向；C 船旁触手吸盘近景和水面接触；D 水下玩家看到巨大黑影/躲避触手；E 安全区回望巨兽沉没。
- 功能：正常路线完整通关、漩涡吸死、触手直接命中、游泳缺氧、计时归零、断点重试、跳过 K4 保持控制权、种子回放复现。
- 视觉：高精近景皮肤不糊；水面坡度与施加的吸力一致；不以离线宣传渲染充当 PIE 验收。

## 关键依赖与分期
