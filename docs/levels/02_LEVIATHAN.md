# 02 · 利维坦：深渊之眼（Leviathan / Eye of the Abyss）

> 状态：设计案 v0.5，**未来章节，不属于克拉肯首发 Vertical Slice**。形态锁定方向：**深海巨鲸 / 古老巨型海兽**，绝不是把利维坦制作成与耶梦加得相似的长蛇。

## 核心体验与差异
深海勘察潜艇在海底断层扫描到一座“海底山脊”，逐渐发现山脊在呼吸，山体表面出现一只不可思议的眼睛。玩家始终在狭小的潜艇驾驶舱里，以声呐、探照灯和导航仪感知巨物；与克拉肯不同，本章重点是**黑暗探测、安静潜航、纵深路线规划与巨颚吸流**，而不是水面触手闪避。

### 场景空间
- 入口：浅层勘探窗口，海水尚可见微弱天光；A 热液矿脉 / 潜艇坠落旧残骸；B 海底“山脊”与巨兽之眼；C 颚口洋流峡道；D 狭窄岩层与深海断层；E 上升水流与安全回收区。
- 巨兽主体远大于潜艇，部分皮肤看起来是岩壁、附着藤壶与海底沉积物；要用海底沉船、声呐距离圈和潜艇窗强化尺寸感。
- 环境具有竖直路线，可下降入沟，也可利用障碍遮蔽；禁止将海底迷雾做得全黑以至方向不可读。

## 逃生阶段与连锁反应（v0.5）

| 阶段 | 玩家做出的主动决策 | 利维坦如何改变下一阶段 | 完成/失败 |
|---|---|---|---|
| L0 勘探 | 在安全海域试用声呐、探照灯、上浮/下潜、静默推进，辨识“地形”回波 | B 区巨大“岩壁”随呼吸缓慢移动 | 到达 B 观测点进入 L1；无主计时 |
| L1 山峦睁眼 | 玩家保持自由视角，透过舷窗看到山脉般的皮肤和缓慢睁开的巨眼 | 巨鲸的胸鳍掠过，潜艇声呐由海床轮廓变成生物轮廓 | 眼/巨鲸身份和尺度可辨、演出节点完成→`RevealComplete`；当前档位主计时开始（Full 960s；克拉肯 Prototype 独立配置） |
| L2 **穿越巨兽身侧** | 根据碎岩/沉船遮护选择何时发出声呐脉冲、何时关闭高噪推进；**探测有方向收益，也有暴露成本** | 噪声引发三级可见反应：巨眼转向 → 胸鳍挪动/水流紊乱 → 巨鲸调整方向，压缩通往 C 区的航线 | 通过 B→C 航门进入 L3；初次暴露可静默+藏入遮护区恢复，只有真实挤压/重大撞击/超时失败 |
| L3 **横穿深渊巨颚吸流** | 观察残骸漂移方向，选岩石背流弱流区、横向侧推或高低通道；重点是**利用地形脱险**，不是长按加速硬顶吸力 | 巨鲸随自身游动自然转身张颚，L2 的暴露程度只改变转向时机/角度；即使成功潜行也会发生巨颚阶段，巨口保持真实空间，碎屑擦过舷窗 | 脱离 C 巨颚捕获区、进入 D 海沟入口→L4；小碰擦/偏航可修正，跨进不可恢复的口腔吞没界面或严重碰撞才致命 |
| L4 **声呐穿越坍塌断层** | 尾鳍造成的泥流让探照灯局部失效；用**有限声呐脉冲 + 稳定导航标记**识别 D 区两个高度不同的上升口，择路穿越 | 巨鲸转身时尾鳍擦裂峡谷，崩落岩石与泥流接续 L3 巨鲸活动；离去信号仍可由声呐跟踪 | 沿 D→E 上升航道进入稳定压力回收层，确认岩崩已脱离→L5；偏航可返航，持续越深压界/致命落石/超时失败 |
| L5 深渊归寂 | 停止计时，玩家可自由透过后窗回望 | 巨鲸沉入断层深处，回波从巨大身影逐步消失 | 可跳过收束进入结算 |

### 贯穿三段的因果、难度与调参
- **L2 的察觉状态有后果，但不锁死后续关卡**：L3 的张颚是固定可玩事件，不要求玩家刻意暴露位置才能触发；声呐使用、推进噪声与巨兽距离驱动 `AttentionLevel`（未察觉/观察/搜索/转向）。转向可改变 L3 吸流方向、进入角度或可用遮蔽点，但必须根据潜艇当前深度、侧推力和剩余时间，确保**两条候选逃生路径中至少一条真实可达**。L2 起始隐藏点可帮助玩家减弱或清除观察状态，绝不“被看到即判死”。
- **L3 是地形判断，不复制克拉肯 K2 的动力拔河**。海流视觉来自碎屑、泡沫、舷窗悬浮颗粒，与实际潜艇受力一致；进入巨口前必须有至少一个靠视觉/声呐可定位的横移出口。靠近巨眼/鲸颚的尺度是核心电影体验，不能只显示抽象吸力条。
- **L4 延续同一场灾难**：尾鳍掀起泥沙，先短时间降低视距，再迫使玩家使用在 L2 学到的声呐技巧；声呐脉冲应有短冷却/清晰反馈但不硬性耗尽，另有水下导航标记防止玩家因完全黑屏迷路。
- **Full 主计时 960s，L2/L3/L4 正常目标 220/210/290s，共 720s，容错 240s**；这是 v0.5 的完整章节配置，与旧版 300s 短篇设计不同。阶段没有硬截止；路线信息和短缓冲水域支撑更长的主动游戏节奏。
- 侦测结果分层：低噪可藏匿恢复；强噪后巨鲸改变姿态并产生更大路线风险；只有真实撞毁、被吞、压界及超时会失败。船体轻擦损伤有限，不追加多余能源管理玩法。
- **不得用随机性制造无解**：L3 所有背流遮护点被封、L4 两条上升航道同时塌陷、声呐冷却期间完全无提示，都应视为关卡设计失败；重试需复原噪声级别、鲸鱼朝向、岩崩状态、潜艇损伤和标准剩余时间。

### 明确失败条件与检查点
- **失败**：L2 遭真实致命挤压/撞毁、L3 进入巨口不可恢复吞没区、L4 潜艇重大撞击/越过已预警的深压边界、全局倒计时耗尽。单次被声呐侦测、短暂偏航、轻微擦撞不能立即判死。
- **检查点**：L2/L3/L4 阶段入口恢复玩家朝向、潜艇位置与深度/损伤、巨鲸注意度/朝向、岩崩周期与阶段标准剩余时间；练习重试不计入整章无重试成绩。跳过演出、重新载入不得复用不合理的损坏或吸流状态。

### 终局安全合同与灰盒验证
- 胜利条件：`经 D→E 完成回收路线 && 潜艇处于 E 的稳定压力保护带 && 巨颚吸力与活动岩崩均不覆盖 E`；无需数分钟内浮出海面，也不能因声呐显示“距离足够远”提前通关。
- PIE 测试必须包含三组情景：低噪慢行、主动声呐高噪但正确避险、被搜索后静默恢复；每组均能进入 L3 并正常完成 L4。
- 固定镜头：巨眼转向潜艇、横穿颚口边缘、尾鳍扫断海沟/局部失明、E 区回望。实际截图/视频/性能尚未验证。

## v0.5 时长扩展：深海勘察、侦测压力与垂直逃生

完整首次体验目标 **17–22 分钟**：L0 探索约 4–5 分钟，L1 巨眼揭示约 1–2 分钟，L2/L3/L4 正常逃生 **220/210/290s = 720s**，L5 回望约 1–2 分钟。正式主倒计时 **960s**，初始容错 **240s**。这一预算是未实测的路径目标，不设 3 个独立硬性限时。

| 阶段 | 需要增加的真实游玩内容 | 为什么值得延长 |
|---|---|---|
| L0 非计时探索 | 在热液喷口、沉船测线、异常“山脊”处进行至多三次**可选**脉冲扫描；不同观察点可揭示 B→C 的海沟轮廓和备用岩壁通道 | 探索得出的信息能影响逃生路径，不要求强制全扫描才见鲸 |
| L2 220s | 探照灯辨认第一个掩体 → 声呐/噪声选择暴露路线或隐藏路线 → 在巨鲸眼睛注视下穿过胸鳍附近、再次决定是否主动探测下一通道 | 噪声状态产生可见巨兽反应并影响 L3 入场方位，不能仅仅连续按“静默” |
| L3 210s | 接近巨口前看残骸流向 → 在多个背流弱区横移 → 几乎擦过巨颚边缘时选择高/低通道 | 与克拉肯的吸力拔河不同，重点是预测、地形遮蔽与潜艇深度 |
| L4 290s | 巨鲸尾鳍擦裂海沟、泥流遮挡主灯 → 短时借导航标志和声呐在分层海沟选择上升路径 → 破碎岩区规避，进入 E 稳压带 | 在五分钟左右的最长逃生段，每约 30–60s 提供一次新的可观察目标/航路决定，不用空洞的黑暗和低速来拖时 |

**公平/节奏保护**：L2 被看见不是强制失败；噪声足够低的玩家也应触发固定巨颚剧情，仅改变 L3 环境难度。L3 的两条可达背流路线和 L4 的两个上升口不得随机同时封闭。L0 探索信息只提供路线优势，跳过探索依然能通过中途可读标识逃生。中间利用岩壁背涡作为可观察的安全缓冲点，但可控期间计时继续。玩家不需要管理第四种“能源饥饿”数值来填充时长。

## 巨兽与资产
- 主体为宽厚鲸体、粗大头颅、胸鳍/尾鳍、古老皮肤层、藤壶与微弱生物荧光，口腔有吞吸力。**不使用蛇形盘绕，也不使用克拉肯触手**。
- 美术资产：潜艇内舱与舷窗、外部高精船壳、声呐投影、海底热液喷口、旧沉船、断层峡谷、巨鲸头部/眼部近景和中远景主体。
- 动作：大尺度慢游、睁眼、张口吸流、鳍掠过、沉潜；触发局部沉积物云、岩壁剥落与声场变化。
- 电影镜头：舷窗外巨眼 → 声呐发现身体延绵到显示边界 → 从巨颚吸力中脱出 → 穿过尾鳍划过的深海尘暴 → 后窗目送海兽沉没。
- 视觉门：声呐状态与实际空间吻合、深海有照明参照、镜头能读懂巨鲸不是蛇、潜艇驾驶舱不遮挡必要游戏提示。

## 验收与风险
- 黑暗模式和探照灯开启时都能找到出口；诱发一次静默失败但能重试；吸力有可行逃离方向；上升/下潜操控稳定；五固定镜头捕捉实际运行画面。
- 技术难点：极大尺度近景鲸鱼皮肤、深海体积散射、声呐空间可读性、巨颚附近相对运动和导航碰撞；先用低模 + 深海静态光束验证机制，再开始 Tripo/Blender 高模制作。
