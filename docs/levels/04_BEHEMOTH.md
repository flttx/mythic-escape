# 04 · 贝希摩斯：群山颤动（Behemoth / Mountains Tremble）

> 状态：设计案 v0.5，未来章节。陆地巨兽方向：强壮的四足神话生物，外形借鉴重型哺乳动物、古兽和岩甲，不把它简单做成另一条恐龙或机械巨人。

## 核心体验
玩家沿一座古代山谷遗迹徒步探索，发现远方整座“山丘”慢慢站起来，庞大的贝希摩斯踏地让山谷震动。与海上关卡相比，这一章没有船：**观察巨兽脚步节拍、在稳固地基与锚点抵抗震波，再利用山岩遮挡飞石，穿过崩塌地形找到稳定岩室**。恐惧来自玩家脚下的大地本身变成危险。

### 场景布局
- A 草甸观测站 / 旧石桥；B 山体开裂的低谷；C 巨兽脚步震源前缘与巨石阵；D 崩塌遗迹 / 断桥；E 地下洞穴入口与稳定岩室。
- 关键参照：树木、崖壁、石桥、古柱、遥远废塔。巨兽走过时地形逐级位移，不能所有山都像静态小摆件。

## 三段逃生与最后一脚高潮（v0.5）

| 阶段 | 玩家主动选择与能力 | 贝希摩斯引起的环境变化 | 通过/可恢复失误/失败 |
|---|---|---|---|
| B0 山谷调查 | 通过巨脚印和地面裂隙学习稳固地基、可抓稳的固定锚点及冲刺；识别两条通道 | “山丘”在呼吸，山脊逐渐移动 | 到达 A 观测台→B1；无主计时 |
| B1 山岳起身 | 保持自由第一人称观察，巨兽抬起庞大躯体、散落碎岩 | 巨掌落足前先有抬脚姿态与低频声，落地后震波**延迟**抵达山谷 | 标尺关系与巨兽主体可辨的 `RevealComplete` → 唯一 Full 720s 倒计时 |
| B2 **大地失稳** | 观察下一次落足节拍，在**较短但裂缝多**与**较长但岩基稳定**的谷底路径中选路；按节拍由安全地基/锚点移动到下一处 | 每个落足传播可视地裂与滚动粉尘，**部分踏脚点在震后失效**；巨兽移动持续改变路线 | 穿过 B→C 的稳定石基→B3；轻震跌坐、偏移可爬起，陷入深裂缝/落崖/超时才判失败 |
| B3 **飞石与崩桥** | 观察肩部擦崖后的碎岩飞行轨迹，在**岩壁遮护点、旧桥与旁侧绕行路**间选择，不断寻路至 D | 巨兽肩部实实在在擦断崖壁，山体落石在音画预警后接近，局部断桥改变通路 | 穿过 C→D 到岩门坡地→B4；轻小石头导致失衡可继续，大型直击/深坠/超时才失败；改道仍可达 |
| B4 **巨兽最后一步** | 玩家望见贝希摩斯远处巨足正缓慢抬起，**主动冲向岩门、一次清楚的拉门操作、进入 E 稳定岩室**，而非复杂谜题 | 巨足落下引发本章最大震动，岩门外旧桥/山谷塌落，震波从洞口外呼啸而过；玩家从受保护的岩室仍能看到巨大身体 | 进入岩室且危险不会覆盖该处→B5；抵达门前可读倒计时式环境前兆，普通延误有可调整路线，落崖/致命坍塌/主计时到 0 才失败 |
| B5 群山归静 | 停表，在安全洞口自由观察 | 巨兽渐远，远处脚步仍引起地面轻震，近处岩层稳定 | 可跳过结尾并结算 |

### 逃生阶段的连续因果
- **B2 是地面结构危险**。普通石柱不能挡住从地下传播的震波；能抗住失衡的只有稳固基岩平台、固定握点以及震后相对安全的移动窗口。对玩家而言，震动不只是“红灯停”，还改变下一步可以踩的地面。
- **B3 是空中危险**。B2 中受损山体在贝希摩斯肩部擦崖时开始飞石/崩桥，必须观察岩块轨迹和空间掩体。设计两种路线：原桥较快却有断裂风险，岩壁旁路更稳但更远；同一落石事件不允许同时封闭所有出口。巨大崩塌优先使用预导演出和局部 Chaos 碎片，不要求整个山脉动态物理。
- **B4 的高潮属于巨兽直接行动，不是凭空定时的石门机关**。上一阶段的山崩阻碍洞口，玩家需抢在最终落足引发的冲击前拉开最后一道岩门。巨足抬起、石砾升起、远方响动逐步加强，洞门和安全岩基位置明确。允许慢速完成，但按正常难度存在足够可操作窗口；不设计突然加速的脚掌或无法闪避的随机砸脚。
- 从 B1 到 B4，每段至少一次看到巨兽肢体、脚步或被其移动影响的地形；结尾才能在岩室中看见它仍像一座移动山脉。

### 时间、公平性、终局
- **Full 主计时 720s，B2/B3/B4 正常目标 180/200/160s，合计 540s、容错 180s**。震波、飞石和最后岩门各有可玩子节拍；不得靠被迫等待脚步周期或附加隐藏死亡计时来凑时长。
- 对于地震、断裂地形、飞石、最后一次落足的威胁，预警时长依据玩家**从当前实际位置到稳定脚点/掩体的可达时间**测试。轻错能站稳、改道或重试，只有真实陷入致命区域才失败；落石不许预警前完成碰撞。
- **最终 B4 的故事震动只发生在玩家仍可安全抵达的条件下**。若玩家晚到，导演可显示巨足持续施压的视觉/音频而不突变无解死局；当主倒计时耗尽或玩家进入致命塌陷时才失败，不能额外引入比主计时更严格的隐形倒计时。
- 胜利：`已完成 B4 拉门+进入 E 岩室 && 位于稳定岩基受保护体积 && 未来一轮脚步的地裂/碎石不能波及 E`。不能仅触到洞口便自动通关，也不能要求玩家站在洞外承受剧情必死坍塌。
- 检查点 B2/B3/B4 恢复桥梁状态、震波节拍、危险碎岩、玩家位置和该段公平的剩余时间。灰盒首先验证两种 B2 落脚路线、B3 遮护/绕道、B4 短拉门与最终落足跨镜头同步、可通关及可预见失败。

## v0.5 时长扩展：山谷地形持续失稳，而非反复躲震

首次完整体验目标 **14–18 分钟**：B0 山谷调查约 2–3 分钟，B1 巨兽起身约 1–2 分钟，B2/B3/B4 目标 **180/200/160s = 540s**，B5 回望约 1–2 分钟。正式主倒计时 **720s**、容错 **180s**。一次脚步等待过久不等于“增加了玩法”。

| 阶段 | 可操作扩展节点 | 不能删的特色 |
|---|---|---|
| B0 非计时探索 | 从旧石桥到观测台，发现巨大足印与先前受损的基岩，尝试抓稳锚点、查看安全岩室方向；可选旁路认识石桥结构 | 玩家预判哪里稳固，后续不用凭空出现的 HUD 箭头找路 |
| B2 180s | 首轮轻震学会地表裂纹与稳固脚点 → 脚步节拍改变一处短路/长稳分支 → 穿过第二处脆弱平台 | 巨兽足部动作引发地面危险，玩家要选路而不只是待着等震 |
| B3 200s | 巨兽肩部擦崖触发第一波飞石 → 借岩壁/古柱挡空中碎片 → 一座旧桥开始断裂，玩家选桥面快路或山壁旁路 | 地下震波和空中落石有不同受力/遮蔽逻辑，且剧场崩塌有真实可达备用路 |
| B4 160s | 残破遗迹标识引导岩门 → 远处巨足缓慢抬起形成预警 → 玩家短交互拉开岩门，赶在最后一次震波前进入 E 的稳定石室 | 玩家参与最后一步高潮，不把守门机关演变为需要两分钟的谜题 |

**公平/节奏保护**：允许震波之间进入稳定岩盘观察移动山岳，但世界时间照走；不得用多次相同的无解坍塌延长关卡。B4 的“最后一脚”沿用全局主计时逻辑，不增设不可见的第二个死亡秒表。B2/B3 有明确短险/长稳路线，检查点恢复毁桥、脚步周期和安全地点。岩室必须在灾害物理范围内真正安全。

## 巨兽、素材与尺度
- 体形：山岳级厚重四足躯体、宽背、巨大足掌、岩甲/角质/厚皮、附生苔藓和碎石。四足行走应具有**沉重重心和缓慢地面接触**，不能用普通动物跑步动画倍速放大。
- 资产：可远观主体与相机附近的脚掌/鳞甲高精片段、山谷地形、石桥和神庙遗迹、树、可崩落岩块、尘暴、地面裂痕。
- 声：震波的低频先行、岩体劈裂、树折声，聋哑/低音设备用户依靠地表提示可完成。
- 视觉门：巨兽相比石桥的大小比例、落足到震波传来的延迟、崩塌近景、尘暴中遗迹引导、洞口回望。

## 验收
- 三次脚步周期玩家都可以按照预测节拍通过；固定抓稳点真正减轻地面震动导致的失衡，岩壁真正遮挡飞石而非直接消除地下震波；所有断桥后仍有物理可走路径；尘暴下仍可辨方向；安全岩室位置不受错误冲击；同一随机种子落石可重复重现。
- 先做**灰盒地震节奏 + 掩体 + 路线**，再考虑高密度地形和高模碎裂。主要风险：动态地形与碰撞不同步、巨兽脚步与地面特效不一致、过强镜头震动。
